  • Profile generalization across training time, not only at the final step.

05.3 / PROJECT 03

LMPool

Multi-GPU LLM serving, engineered around cache locality.

MY SCOPE
Architecture Global and local scheduling Transactional KV transfer Benchmark design Correctness tests

THE CENTRAL TENSION

01

Routing does not account for cached prefixes.

Requests wait behind repeated prefill work even when a reusable KV prefix already exists elsewhere.

02

Routing only to the owner creates load imbalance.

A high cache hit rate is not useful if the selected GPU is overloaded and its queue keeps growing.

03

Routing uses projected cost; transfer requires a measured benefit.

LMPool combines missing prefill, queue work, reclaim pressure, and capacity feasibility to choose where a request should run.

DESIGN RULE

Metadata crosses the control plane. KV tensors travel directly between paired model runners over NCCL/NVLink. Destination blocks stay invisible until publication.
